# Security Policy

## Supported Versions

This repository has no release history. Security fixes are applied to the latest
commit on the default branch. No backporting is provided.

| Version | Supported |
| --- | --- |
| Latest commit on `main` | :white_check_mark: |
| Older commits, tags, and forks | :x: |

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.** Public disclosure
gives attackers time to exploit the problem before a fix is available.

GitHub private vulnerability reporting is not currently enabled for this
repository. Report the issue by contacting the repository developer privately
through a GitHub direct message to [@f0xb17](https://github.com/f0xb17).

Alternatively, the repository maintainer can enable private vulnerability
reporting under **Settings → Code security → Private vulnerability reporting**,
after which reports should be submitted through the **Security** tab →
**Report a vulnerability**.

## What to Include

Please provide as much of the following as you can:

- A description of the vulnerability and the affected component or file
- Steps to reproduce the issue
- The potential impact if the vulnerability were exploited
- A proof of concept, when available
- The affected version, commit, or environment

## What to Expect

- Maintainers aim to acknowledge reports within 7 days. This is a target, not a
  guarantee.
- Please allow 90 days for a fix before public disclosure. This is a target
  timeline as well; remediation time may depend on severity and complexity.
- You will be kept informed of progress and of any decision to adjust the
  timeline.

## Out of Scope

The following are out of scope for this policy:

- Vulnerabilities in third-party dependencies. Report these to the upstream
  project; a note here is welcome if this repository needs to act on them.
- Social engineering attacks against maintainers or contributors.
- Attacks that require physical access to a device.

Nothing in this section means dependency vulnerabilities should be ignored or
left unaddressed.
